5. Preview 自测清单（勾完即可交）

  1. □ 入口能分别进父母端 / 子女端
  2. □ 父母：首页 → 钙片 →「我吃了」→ 回首页
  3. □ 父母：首页 → 紧急 → 呼叫中 → 取消回首页
  4. □ 子女：晓安 → 用药 → 家庭 →（设置）→ 回家庭
  5. □ 紧急：呼叫中 → 来电 → 接听 → 挂断
  6. □ 底部 Tab 在晓安 / 用药 / 家庭之间能互跳
省时间策略：先只做标了「必连」的热区（大约 18 个），三条主路径通了再补「建议 / 可选」。
